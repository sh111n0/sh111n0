## Proyectos públicos destacados

### [API de gestión de usuarios con .NET](https://github.com/sh111n0/UserManagement-API-DotNet)

API REST desarrollada con .NET 8, Entity Framework Core y MySQL. Incluye operaciones CRUD, inicio de sesión, validación de datos, contraseñas protegidas con BCrypt y documentación mediante Swagger.

**Evidencia:** C#, arquitectura por capas, DTO, repositorios, servicios, Entity Framework Core, MySQL y diseño de endpoints REST.

### [Aplicación Android de gestión de usuarios](https://github.com/sh111n0/UserManagement-Android-Kotlin)

Aplicación Android que permite registrar usuarios e iniciar sesión mediante una API REST. Utiliza Kotlin, Retrofit y Gson, con validaciones de formularios y manejo de respuestas del servidor.

**Evidencia:** Kotlin, Android, consumo de APIs REST, Retrofit, JSON y validación de interfaces.

### [Control de conjunto residencial](https://github.com/sh111n0/LenguajeModelado)

Aplicación Java 21 con interfaz gráfica Swing y modo de consola. Gestiona visitantes, residentes, personal, espacios, movimientos y asignaciones mediante clases, herencia, colecciones y validación de fechas.

**Evidencia:** Java, programación orientada a objetos, herencia, colecciones, Swing, Maven y validación de datos.
